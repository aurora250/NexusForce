# NeForce AES-256 性能评估

## Linux

> 测试平台: i9-13980HX (8 P-core + 16 E-core), Linux 7.0.0-42, GCC 13.3.0 Release (`-O2 -DNDEBUG -mavx2 -maes -mpclmul -mvaes -mvpclmulqdq`)

### ECB 加密 (EcbEncrypt/*)

|   数据 |     NeForce | OpenSSL EVP |    比值 |
|-------:|------------:|------------:|--------:|
|   16 B | **0.058 µs** |    0.286 µs | **0.20×** |
|   64 B | **0.062 µs** |    0.288 µs | **0.22×** |
|  256 B | **0.076 µs** |    0.296 µs | **0.26×** |
|  1 KiB | **0.142 µs** |    0.362 µs | **0.39×** |
|  8 KiB | **0.813 µs** |     1.03 µs | **0.79×** |
| 64 KiB | **6.41 µs** |     6.70 µs | **0.96×** |

- 16 B ~ 1 KiB 为 0.20× ~ 0.39×，差距主要来自 OpenSSL EVP 每次调用的上下文初始化
- 8 KiB 起进入 0.79×；64 KiB 6.41 µs 对 6.70 µs（0.96×），单次调用与 OpenSSL 基本持平
- 延迟随尺寸近似线性：8 KiB → 64 KiB 为 7.9 倍（0.813 → 6.41 µs），无明显缓存悬崖

|------------:|-------------:|------------:|
|    ECB 加密 | **9.52 GiB/s** | 9.12 GiB/s |
|    ECB 解密 | **9.56 GiB/s** | 9.11 GiB/s |
|    CBC 加密 |     1.70 GiB/s | 1.72 GiB/s |

### 优化前后 (Gcm/*)

|           场景 | 优化前 (128 位路径) |   优化后 (VAES 8 块) |     变化 |
|----------------|--------------------:|---------------------:|---------:|
| GCM 64 KiB 加密 |     14.7 µs / 1.48× | **8.49 µs / 0.89×** | **−42%** |
| GCM 64 KiB 解密 |     14.1 µs / 1.44× | **8.40 µs / 0.90×** | **−40%** |
|  GCM 8 KiB 加密 |     1.88 µs / 1.24× | **1.14 µs / 0.77×** | **−39%** |
|  GCM 1 KiB 加密 |    0.386 µs / 0.68× | **0.254 µs / 0.47×** | **−34%** |

- VAES 8 块内核将 GCM 64 KiB 加解密由 14.7 / 14.1 µs 降到 8.49 / 8.40 µs（−42% / −40%）
- 8 KiB 加密 −39%，1 KiB 加密 −34%；收益随尺寸减小而收窄，小包由固定成本主导
- 比值由 1.24× ~ 1.48× 降至 0.47× ~ 0.90×，全部进入 1.1× 目标以内

## 总结

- **ECB**：0.20× ~ 0.96×；64 KiB 6.41 / 6.39 µs，与 OpenSSL 基本持平；吞吐 9.52 / 9.56 GiB/s
- **CBC**：加密 0.18× ~ 1.01×（64 KiB 略慢 1%），解密 0.19× ~ 1.03×；解密吞吐 8.86 GiB/s
- **GCM**：VAES 路径 0.33× ~ 0.90×，64 KiB 反超约 10%；默认 128 位路径 64 KiB 约 1.1× ~ 1.3×；吞吐 7.19 / 7.27 GiB/s
- **小包**：≤1 KiB 由 OpenSSL EVP 初始化成本主导，NeForce 各模式均为 0.18× ~ 0.68×

## 可优化方向

| 方向                                                          | 预期收益                                  | 复杂度 |
|---------------------------------------------------------------|-------------------------------------------|:------:|
| 非 VAES 平台的 128 位内核显式交错 AES 轮与 GHASH 乘加         | 64 KiB GCM 由 1.26× 降至约 1.1×           |   高   |
| 单次调用内复用轮密钥与 H 幂（批量小包 API）                   | ≤256 B 小包再快 5% ~ 10%                  |   中   |
| GCM 末块 GHASH 与长度块归约合并                               | 每包省一次 256 位归约                     |   低   |
| 基准补充 4 KiB / 16 KiB 档位与 OpenSSL 上下文复用对照         | 覆盖更多真实负载                          |   低   |
