## 总结

- 表格解析 **42.6 µs**，为 md4c 的 **0.86×**；围栏代码 **1.59×**
- 段落、列表、混合文档分别为 **2.85×**、**5.13×**、**3.51×**
- 所有 54 个 Markdown 单元测试通过；`parse → build → parse` 结构保持等价
- 结构上节点与子数组全部位于 `markdown_document` 的 `bump_arena`，字符串为 `string_view`，无逐节点堆分配

## 可优化方向

| 方向 | 预期收益 | 复杂度 |
|------|----------|:------:|
| 单遍行分类缓存（blank/heading/fence/list/quote/indent 一次扫描） | 解析减少 15%~25% 重复行扫描 | 中 |
| 块级节点压缩为 16~32 字节载荷 + 指针（当前 168 字节） | 列表/混合文档减少节点复制与缓存压力 | 高 |
| 行内节点压缩为 32 字节（链接数据外置） | 段落与行内密集文档再快 20%~30% | 中 |
| 列表项行视图复用与列表容器容量预估 | 列表解析减少 arena 分配 | 低 |
