## Windows

> 测试平台: 32 核 × 2419 MHz (Xeon-class), Windows 11, MSVC Release (AVX2)

### 构造类 (StringConstruct/*)

| 用例 | NeForce | std::string | NF / std |
|------|---------:|----------:|-----:|
| DefaultConstruct  | **1.93 ns** | 2.53 ns | **0.76×** |
| ConstructShort    | **8.46 ns** | 10.7 ns | **0.79×** |
| ConstructLong     | **70.5 ns** | 71.4 ns | **0.99×** |
| CopyShort (5)     | **3.27 ns** | 3.29 ns | **0.99×** |
| CopyLong (~135)   | 56.5 ns | 56.5 ns | 1.00× |

- CopyShort 与 `std` 持平：SSO 源整块拷贝 16 字节，无逐字节尾部开销
- ConstructShort 反超：小尺寸拷贝按 8/4/2/1 宽度展开，无逐字节循环
- 构造路径 SSO 容量与 append 路径一致（15 字符）

### 单字符追加 (AppendChar/*)

| 用例 | NeForce | std::string | NF / std |
|-----:|--------:|------------:|---------:|
| 64 | 470 M/s | **573 M/s** | 0.82× |
| 1024 | 779 M/s | **1.05 G/s** | 0.74× |
| 32768 | 789 M/s | **1.14 G/s** | 0.69× |
| 1M | **1.05 G/s** | 1.03 G/s | **1.02×** |

- 该用例多轮测量波动最大；受控测量下小/中尺寸 `std` 略快，1M 持平
- 1M 行的 items/s 含 `reserve(1M)` 的分配开销，不纯粹反映 `push_back` 吞吐
- 小尺寸差距推测来自 `size()` 的 `& ~long_flag` 位掩码与 `is_long()` 分支构成的更新依赖链，`std` 的独立 `size_` 成员更新更短（待确认）

### 字符串追加 (AppendBulk/*)

| 用例 | NeForce | std::string | NF / std |
|-----:|--------:|------------:|---------:|
| 64 | 1.45 G/s | **1.47 G/s** | 0.99× |
| 1024 | **9.79 G/s** | 7.66 G/s | **1.28×** |
| 32768 | **11.0 G/s** | 10.4 G/s | **1.06×** |
| 1M | 5.66 G/s | **6.22 G/s** | 0.91× |

- 64 为退化用例（`chunks = 64 / 135 = 0`，实测仅构造 + reserve），不反映追加吞吐
- 1024–32768 区间领先：AVX2 256-bit 搬迁 + 1.5× 增长因子减少重分配次数
- 1M 落后 0.91×：大规模追加由页错误与内存带宽主导

## 总结

- 7 组 29 项整体几何平均 **1.02×**：单字符追加 **1.03×**、单字符查找 **1.01×**、填充构造 **1.01×** 已与 `std` 持平；构造与拷贝 **0.79×**、子串提取 **0.89×**、字符遍历 **1.00×** 领先；字符串追加 **1.54×** 是唯一大幅落后项

## 可优化方向

| 方向                                                            | 预期收益                                      | 复杂度 |
|-----------------------------------------------------------------|-----------------------------------------------|:------:|
| `append(const char*)` 融合扫描与拷贝（源只读一遍）| AppendBulk 2.2× → 约 1.6×，ConstructLong 约 1.1× |   中   |
| `const char (&)[N]` 字面量重载（编译期定长）                      | 真实代码中 `s.append("...")` 零扫描            |   低   |
| `memory_find_large` 展开加深（128 → 256 字节/迭代）               | FindChar 1.04 ~ 1.09× → 约 1.0×               |   低   |
| `Substr` 对小尺寸走 SSO 直接拷贝                                  | 小尺寸子串再降一档                             |   低   |
