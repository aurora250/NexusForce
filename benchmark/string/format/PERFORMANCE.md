# NeForce format 性能评估

## Linux

> 测试平台: Intel i9-13980HX (8 P-core / 16 逻辑 CPU + 16 E-core), Linux 7.0, Clang 20.1.2 Release (`-O2 -DNDEBUG -std=gnu++20 -mavx2`)

### 整数格式化 (Integer/*)

| 用例             | 模板                   |      NeForce | std::format |  NF / std |
|------------------|------------------------|-------------:|------------:|----------:|
| IntegerDefault   | `"{}"` 42              | **14.20 ns** |    26.06 ns | **0.55×** |
| IntegerPadded    | `"{:06d}"` 1234        | **24.16 ns** |    42.76 ns | **0.57×** |
| IntegerHex       | `"{:#x}"` 0xDEADBEEF   | **28.67 ns** |    35.75 ns | **0.80×** |

### 浮点格式化 (Double/*)

| 用例               | 模板              |      NeForce | std::format |  NF / std |
|--------------------|-------------------|-------------:|------------:|----------:|
| DoubleDefault      | `"{}"` 1/3        |     54.25 ns | **53.68 ns** |     1.01× |
| DoubleGeneral      | `"{:g}"` 1/3      | **49.68 ns** |    55.10 ns | **0.90×** |
| DoubleFixed        | `"{:.3f}"` pi     | **47.85 ns** |    59.05 ns | **0.81×** |
| DoubleScientific   | `"{:e}"` 1234.5   | **50.96 ns** |    57.28 ns | **0.89×** |
| DoubleRightAligned | `"{:>12.4f}"` pi  | **57.70 ns** |    69.60 ns | **0.83×** |

### 字符串与转义 (String/*)

| 用例          | 模板                  |      NeForce | std::format |  NF / std |
|---------------|-----------------------|-------------:|------------:|----------:|
| CStringArg    | `"user={}"` "alice"   | **15.55 ns** |    24.93 ns | **0.62×** |
| EscapedBraces | `"{{literal}} {}"` 42 | **22.99 ns** |    41.03 ns | **0.56×** |

### 多参数与日志行 (Mixed/*)

| 用例         | 模板                      |      NeForce | std::format |  NF / std |
|--------------|---------------------------|-------------:|------------:|----------:|
| MultiMixed   | `"{} {:.1f} {} {}"`       | **108.25 ns** |   130.26 ns | **0.83×** |
| LogLine      | `"[{}] {}:{} {:.1f}ms"`   | **113.11 ns** |   137.75 ns | **0.82×** |
| AppendReuse  | `format_to` + `clear()`   |    139.76 ns | **133.53 ns** |     1.05× |

## 总结

- **整数 0.63×、字符串 0.59×、浮点 0.89×、多参数 0.89×**，整体几何平均 **0.77×**
- 单占位符 `{}`：整数 14.20 ns、字符串参数 15.55 ns；浮点 `{}` 54.25 ns 与 `std::format` 持平

## 可优化方向

| 方向                                                              | 预期收益                            | 复杂度 |
|-------------------------------------------------------------------|-------------------------------------|:------:|
| 排查 `format_to` 复用缓冲的写入开销（同内容 `format` 用例为 0.82×） | `AppendReuse` 1.05× → 1.0× 以内      |   低   |
| `{}` 浮点在 d2s 后直接写输出缓冲（省掉中间缓冲与一次 `append`）     | 浮点默认格式再降 3 ~ 5 ns            |   低   |
| 浮点最短往返的十进制除法进一步收敛（当前每位数一次除法）            | `{}` / `{:g}` 再降 5 ~ 10%           |   中   |
| `uint_to_string_base` 十进制分组扩到 4 位一组（`/10000`）           | 整数再降 2 ~ 3 ns                    |   低   |
| 多参数路径按占位符预计算输出长度，减少缓冲区扩容判断                | `MultiMixed` / `LogLine` 提升 5 ~ 8% |   低   |
| 覆盖 `{:a}` / 十六进制浮点与更多 `std::format` 语义                 | 语义完整度                           |   中   |
