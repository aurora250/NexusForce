const CharT *__restrict__ src,
const size_t count )

复制指定长度的字符串

模板参数
CharT字符类型
参数
dest目标字符串指针
src源字符串指针
count要复制的最大字符数
返回
目标字符串指针

复制最多 count 个字符，如果源字符串长度小于 count，用空字符填充剩余位置。 如果源字符串长度大于等于 count，不会自动添加终止空字符。

注解
使用restrict关键字优化，要求源和目标内存不重叠，否则将产生未定义行为。
