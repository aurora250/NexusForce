详细描述

常量缓冲区序列（scatter-gather 写）

包含多个只读内存区域的视图，用于一次 scatter-gather 写操作。 异步写入时数据依次从每个缓冲区发送。

注解
缓冲区序列不拥有底层内存，调用者需确保内存在操作期间有效。
