template<typename T>
class neforce::weak_ptr< T >

弱智能指针类模板

模板参数
T对象类型

弱智能指针用于观察由共享智能指针管理的对象，但不拥有对象的所有权。 不会增加对象的引用计数，因此不会阻止对象被销毁。

特性：

  • 不增加对象引用计数
  • 可检测对象是否已被销毁
  • 可安全地升级为shared_ptr
  • 支持所有权比较和排序
  • 线程安全的过期检测
注解
弱指针本身是线程安全的，但升级后的共享指针需要单独管理
