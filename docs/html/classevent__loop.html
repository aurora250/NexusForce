详细描述

单线程 I/O 事件循环

监控已注册的文件描述符的可读/可写事件，并在事件发生时调度回调。 定时器以最小堆管理，到期时自动触发。

注解
所有回调在事件循环线程中执行，长耗时回调会阻塞 I/O 分发。
警告
不支持从其他线程注册 fd；通过 wake() + 外部队列实现跨线程操作。
