详细描述

HTTP负载均衡管理器

管理多个后端节点，按策略分发请求。 支持主动健康检查和故障转移。

使用示例：

load_balancer lb;
lb.add_backend({"web1", ports(8080)});
lb.add_backend({"web2", ports(8080)});
lb.set_strategy(lb_strategy::LEAST_CONNECTIONS);
auto* backend = lb.select_backend();
if (backend) {
// 转发请求到 backend
lb.release_backend(backend); // 请求完成后调用
}
