template<typename T, typename Alloc = allocator<list_node<T>>>
class neforce::list< T, Alloc >

双向链表容器

模板参数
T元素类型
Alloc分配器类型

双向链表容器，提供常数时间的插入和删除操作。 不支持随机访问，但支持双向迭代。
