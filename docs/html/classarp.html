ARP协议实现类

提供ARP地址解析功能，将IPv4地址转换为MAC地址。 需要在本地网络中有效，目标主机必须在线且可达。

主要功能：

  • 从IP地址解析MAC地址
  • 支持超时控制
  • 支持指定网络接口
