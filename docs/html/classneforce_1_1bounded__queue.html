template<typename T>
class neforce::bounded_queue< T >

线程安全的有界环形队列（非阻塞）

模板参数
T元素类型

基于环形缓冲区实现，push/pop 为 O(1) 操作。 调用者需自行处理满队列时的溢出策略。
