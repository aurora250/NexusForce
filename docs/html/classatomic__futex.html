template<uint32_t WaiterBit = 0x80000000>
class atomic_futex< WaiterBit >

原子快速用户态互斥锁类模板

模板参数
WaiterBit等待者标志位，默认为0x80000000

基于FUTEX实现的用户态互斥锁， 提供高效的线程同步机制，减少不必要的上下文切换。
