详细描述

统一异步操作核心

合并 I/O 多路复用（epoll/IOCP）、定时器管理和工作投递。 所有异步操作以此为调度目标，替代分散的 event_loop 和 thread_pool 实例。

使用示例：

io_context ctx;
ctx.post([] { println("async work"); });
ctx.schedule_timer(1000, [] { println("1 second later"); });
ctx.run(); // 驱动事件循环

注解
单线程 run() 时所有 handler 串行执行，无需加锁。多线程 run_pool() 时需 strand。
警告
跨线程 post() 是线程安全的；add_fd/remove_fd 必须在 run() 所在线程调用。
