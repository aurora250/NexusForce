template<typename P = EmptyProps>
class Component< P >

组件模板

模板参数
P属性类型，父组件向子组件传递的只读参数

所有 TUI 组件应继承此类并实现 render()。 Props 通过 setProps() 注入，在组件生命周期内保持不变。
