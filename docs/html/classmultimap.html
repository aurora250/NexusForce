详细描述

template<typename Key, typename T, typename Compare = less<Key>, typename Alloc = allocator<rb_tree_node<pair<const Key, T>>>>
class multimap< Key, T, Compare, Alloc >

多重映射容器

模板参数
Key键类型
T值类型
Compare键比较函数类型，默认为less<Key>
Alloc分配器类型

multimap是一种关联容器，存储键值对（key-value pairs），允许重复键。 元素按照键的顺序自动排序，排序标准由Compare函数对象指定。 支持快速的键查找，但键可以重复出现。底层使用红黑树实现。
