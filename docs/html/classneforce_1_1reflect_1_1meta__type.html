详细描述

类型反射元数据类

描述一个类型的完整反射信息，包括：

  • 类型基本信息（名称、大小、ID）
  • 继承关系（基类列表）
  • 属性列表（成员变量）
  • 函数列表（成员函数和静态函数）
  • 构造函数
  • 枚举信息
  • 容器信息
  • 克隆工厂
