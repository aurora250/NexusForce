template<typename... Types>
struct variant< Types >

变体类型主模板

模板参数
Types可存储的类型列表

variant是一个类型安全的联合体，可以在运行时存储多种不同类型的值。 使用函数指针表实现各种操作，支持构造、赋值、访问、销毁等操作。
