IPv4头部结构定义

定义IPv4数据包的头部格式，用于原始套接字操作。 使用位域精确匹配IPv4头部字段布局。

IPv4头部格式：

  • 版本(4位) + 头部长度(4位)
  • 服务类型(8位)
  • 总长度(16位)
  • 标识(16位)
  • 标志(3位) + 片偏移(13位)
  • 生存时间(8位)
  • 协议(8位)
  • 头部校验和(16位)
  • 源地址(32位)
  • 目的地址(32位)
