详细描述

HTTP Chunked Transfer Encoding 读取器

按RFC 7230第4.1节实现分块传输解码。 从socket逐块读取数据，处理chunk-size、chunk-data、trailer。

使用示例：

chunked_body_reader reader(socket);
byte_vector chunk;
while (reader.next_chunk(chunk)) {
process(chunk);
}
// 读取trailer
auto trailers = reader.trailers();
