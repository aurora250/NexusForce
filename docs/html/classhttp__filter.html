HTTP过滤器基类

所有HTTP过滤器的抽象基类，定义了过滤器的生命周期方法。

过滤器生命周期：

  1. pre_filter：请求处理前调用
  2. do_filter：实际处理
  3. post_filter：响应发送前调用
