template<typename Clock>
class timer_scheduler< Clock >

定时任务调度器

模板参数
Clock时钟类型

管理所有定时任务的调度和执行。使用独立的线程运行调度循环， 基于时间点对任务进行排序，并在任务到期时执行回调函数。
