template<typename Func>
class scope_exit< Func >

作用域退出守卫

模板参数
Func可调用对象类型

在作用域退出时无条件执行指定的函数（无论是否发生异常）。

注解
守卫对象的析构函数不应抛出异常。 如果函数可能抛出异常，建议使用scope_fail或scope_success。
