详细描述

健康检查端点过滤器

拦截预配置路径的 GET 请求，返回 JSON 格式的健康状态。 支持自定义健康检查回调（如数据库连接、Redis可达性等）。

响应格式： {"status":"ok","uptime":12345,"checks":{"db":"ok","redis":"ok"}} 非健康状态返回 503。
