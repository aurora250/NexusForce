详细描述

virtual_thread_task 的 void 特化版本

表示一个返回 void 的异步任务，支持 co_await 等待和 get_result() 同步获取结果。 任务结果（或异常）存储在引用计数的堆对象中，确保协程帧销毁后仍可安全访问。
