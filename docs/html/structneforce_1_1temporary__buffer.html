template<typename Iterator>
struct neforce::temporary_buffer< Iterator >

临时缓冲区类

模板参数
Iterator迭代器类型

管理临时内存缓冲区的RAII包装器，用于算法中需要临时存储的场景。 自动管理内存分配和释放，确保异常安全。
