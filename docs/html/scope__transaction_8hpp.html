RAII事务作用域守卫

提供异常安全的事务管理，构造时自动开始事务，析构时根据提交状态决定提交或回滚。

使用示例：

void do_work(auto& conn) {
scope_transaction tx{conn}; // BEGIN
conn.update("INSERT INTO ...");
conn.update("UPDATE ...");
tx.commit(); // COMMIT
// 如果未调用 commit() 或发生异常，析构时自动 ROLLBACK
}
