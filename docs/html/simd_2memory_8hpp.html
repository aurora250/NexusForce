跨平台 SIMD 内存操作

提供对齐/非对齐加载与存储、流式（非 temporal）访问及软件预取操作， 覆盖 128-bit / 256-bit / 512-bit 向量宽度。 自动派发至 SSE2 / AVX / AVX2 / AVX-512F / NEON 或标量回退。
