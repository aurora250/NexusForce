HTTP过滤器链实现

此文件提供了HTTP过滤器链的实现，用于在HTTP请求处理过程中 进行预处理和后处理。支持多种内置过滤器：CORS、日志记录、 静态文件服务、限流、认证等。

主要功能：

  • 过滤器链管理
  • 预过滤和后过滤
  • CORS跨域支持
  • 请求日志记录
  • 静态文件服务
  • 请求限流
  • 认证授权
