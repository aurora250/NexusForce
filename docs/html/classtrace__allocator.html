template<typename T>
class trace_allocator< T >

内存追踪分配器

模板参数
T分配的元素类型

提供内存分配追踪功能的分配器适配器。 在分配内存时记录调用栈，在释放内存时清除记录。 析构时检查是否有未释放的内存，并输出详细的泄漏信息。
