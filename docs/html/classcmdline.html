详细描述

命令行参数解析器

支持解析符合POSIX风格和GNU风格扩展的命令行参数。 特性：

  • 长选项（–option）和短选项（-o）
  • 选项值（–option=value 或 -o value）
  • 多值选项
  • 默认值
  • 位置参数
  • 自动生成帮助信息
