详细描述

层级化日志记录器

每个 logger 有唯一的名称（如 "app.network.tcp"）， 通过 '.' 分隔形成层级。子 logger 默认继承父 logger 的级别。

主要功能：

  • 运行时级别过滤与继承（INHERIT 标记）
  • 同步 / 线程池异步双模式
  • COW 上下文（零拷贝共享）
  • 自定义过滤器
  • 多 sink 输出
  • 自动刷新
