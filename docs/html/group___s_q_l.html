SQL语句的流式构建器实现

通过链式调用构建复杂的SQL语句，避免手动拼接SQL字符串的安全风险。

支持的语句类型：

  • DML: SELECT, INSERT, UPDATE, DELETE
  • DDL: CREATE TABLE, ALTER TABLE, DROP TABLE, TRUNCATE TABLE
  • 视图: CREATE VIEW, DROP VIEW
  • 索引: CREATE INDEX, DROP INDEX
  • 集合操作: UNION / UNION ALL / INTERSECT / INTERSECT ALL / EXCEPT / EXCEPT ALL
  • CTE: WITH / WITH RECURSIVE
  • 窗口函数: ROW_NUMBER, RANK, DENSE_RANK, NTILE, LEAD, LAG, FIRST_VALUE, LAST_VALUE
  • 表达式工具: CASE, CAST
  • 聚合: COUNT, SUM, AVG, MAX, MIN

遵循的国际标准

本构建器生成的语法遵循以下国际标准：

  • ISO/IEC 9075:1992 (SQL-92) Entry 级及 Intermediate 级核心语法 https://www.iso.org/standard/16663.html
  • ISO/IEC 9075-2:1999 (SQL:1999/Foundation) CTE、派生表与子查询增强 https://www.iso.org/standard/26196.html
  • ISO/IEC 9075-2:2003 (SQL:2003/Foundation) 窗口函数 (ROW_NUMBER / RANK / 等)
  • ISO/IEC 9075-2:2008 (SQL:2008/Foundation) TRUNCATE TABLE, FETCH FIRST 分页
  • ISO/IEC 9075-4:2023 (SQL/PSM) 预编译占位符相关约定 https://www.iso.org/standard/76584.html

同时覆盖以下事实标准（跨数据库厂商通用，非 ANSI 标准正文）：

  • CREATE INDEX / DROP INDEX
  • CREATE [OR REPLACE] VIEW
  • IF [NOT] EXISTS 修饰子句
  • AUTO_INCREMENT 自增列 (MySQL/SQLite)
  • LIMIT / OFFSET 分页 (MySQL/PostgreSQL/SQLite)

数据库兼容性

生成的 SQL 语句适用于以下主流关系型数据库：

  • MySQL 5.7+
  • PostgreSQL 9.0+
  • SQLite 3.0+
  • Microsoft SQL Server 2008+
  • Oracle Database 10g+
  • 所有其他遵循 ANSI SQL 标准的数据库
注解
  • LIMIT/OFFSET 是事实标准，被除 Oracle 外的多数数据库支持。 对 Oracle 12c+，建议使用 fetch_first() 生成 FETCH FIRST n ROWS ONLY。
  • 构建器生成的 SQL 骨架使用 ? 占位符；实际参数绑定与转义由驱动程序处理。

有意不纳入的特性及原因

以下 SQL 特性在标准中有定义但本构建器 **不提供 API 支持**。 用户可通过传入原始 SQL 字符串（如 where()、having() 等）自由使用这些特性。

特性 标准出处 不纳入原因
GRANT / REVOKE SQL-92 Entry DCL（数据控制语言），属于运维授权范畴，与 DML/DDL 性质不同
CREATE SCHEMA / DOMAIN / ASSERTION SQL-92 Intermediate 生产代码中极少使用；多数数据库实现不完整或语义差异大
TRIGGER / 存储过程 / 函数 SQL:1999 / SQL/PSM 过程式代码（含控制流），超出声明式 SQL 构建器的设计范围
SAVEPOINT / RELEASE SAVEPOINT SQL:1999 事务控制原语，粒度与连接层绑定；使用频率低
MERGE (UPSERT) SQL:2003 各数据库方言差异极大（MySQL ON DUPLICATE KEY / PostgreSQL ON CONFLICT / SQLite INSERT OR REPLACE），统一 API 会掩盖方言行为差异
CREATE SEQUENCE / ALTER SEQUENCE SQL:2003 多数项目通过 ORM 或迁移脚本管理序列，不适合运行时 SQL 构建器
MATCH / OVERLAPS / UNIQUE 谓词 SQL-92 Full 边缘用例；多数数据库未实现或语义不完整，生产代码中几乎不会使用
LATERAL JOIN SQL:1999 使用率极低；可通过子查询或 CROSS JOIN 改写
IDENTITY 列 (GENERATED AS IDENTITY) SQL:2003 与 AUTO_INCREMENT 功能重叠；各数据库语法差异大 (GENERATED ALWAYS AS IDENTITY / GENERATED BY DEFAULT AS IDENTITY / IDENTITY(1,1))
TEMPORARY TABLE (会话临时表) SQL-92 Full 本构建器已支持 CREATE TEMP TABLE (事实标准语法)
