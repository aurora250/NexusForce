详细描述

IP地址封装类

封装IPv4和IPv6地址，提供统一的访问接口。

主要功能：

  • IPv4和IPv6地址的统一表示
  • 地址解析
  • 地址格式化
  • 获取地址族、端口等信息
  • 通配地址和回环地址生成
  • 地址比较
