详细描述

信号管理器

统一管理跨平台的信号处理，提供异步信号分发机制。

特性：

  • 单例模式
  • 线程安全的信号注册和分发
  • 支持信号队列
  • 支持超时信号
  • 支持自定义事件
  • 信号守卫
