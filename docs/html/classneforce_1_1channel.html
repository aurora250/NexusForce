详细描述

template<typename T>
class neforce::channel< T >

有限容量的 CSP 消息通道

模板参数
T消息类型

支持多生产者/多消费者的线程安全消息通道。 容量为 0 表示无缓冲（同步握手），capacity_max 表示无上限。

注解
容量耗尽时写入阻塞，无数据时读取阻塞。
