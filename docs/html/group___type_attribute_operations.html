模板参数
T1第一个类型
T2第二个类型

三目运算符的类型推导规则：

  1. 如果T1和T2是相同类型，则整个表达式的类型是该类型
  2. 如果T1和T2是不同的类型，编译器会尝试找到一个公共类型
  3. 转换规则通常基于标准的隐式类型转换规则
