完成令牌模型

完成令牌允许同一 async_xxx 函数根据 token 参数返回不同结果类型。

  • 默认（callable）：void，handler 即回调
  • use_future：返回 future<Result>
  • detached：fire-and-forget，void
  • deferred：延迟执行，void
