HTTP状态码枚举

定义了标准的HTTP状态码，按响应类别分组：

  • 1xx：信息性状态码
  • 2xx：成功状态码
  • 3xx：重定向状态码
  • 4xx：客户端错误状态码
  • 5xx：服务器错误状态码
枚举值
