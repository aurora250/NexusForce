HTTP状态码枚举

定义了标准的HTTP状态码，按响应类别分组：

  • 1xx：信息性状态码
  • 2xx：成功状态码
  • 3xx：重定向状态码
  • 4xx：客户端错误状态码
  • 5xx：服务器错误状态码
枚举值
S1_CONTINUE 

100 Continue 服务器收到请求头，客户端可以继续发送请求体

S1_SWITCH_PROTOCOL 

101 Switching Protocols 同意切换协议

S2_OK 

200 OK 请求成功

S2_CREATED 

201 Created 请求成功并创建了新资源

S2_NO_CONTENT 

204 No Content 请求成功但无内容返回
