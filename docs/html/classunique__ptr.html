template<typename T, typename Deleter = default_deleter<T>>
class unique_ptr< T, Deleter >

独占智能指针

模板参数
T元素类型
Deleter删除器类型，默认为default_delete<T>

管理动态分配对象的独占所有权，确保对象在离开作用域时被正确删除。
