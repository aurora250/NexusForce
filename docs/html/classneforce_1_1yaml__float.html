YAML浮点数值类型

表示YAML中的浮点数值。存储为IEEE 754双精度浮点数（double）。 支持YAML中的特殊浮点值：

  • 无穷大：.inf、.Inf、.INF
  • 负无穷大：-.inf、-.Inf、-.INF
  • 非数字：.nan、.NaN、.NAN
  • 科学记数法：1.23e+4、5.67E-10
