template<typename Key, typename Value>
class neforce::lru_cache< Key, Value >

LRU缓存类模板

模板参数
Key键类型
Value值类型

实现LRU（最近最少使用）缓存淘汰策略的容器。 当缓存达到容量上限时，会淘汰最长时间未被访问的条目。

特性：

  • O(1)时间复杂度的插入和访问
  • 支持缓存项过期时间
  • 支持条件删除
注解
此类不是线程安全的，多线程环境下需要外部同步
