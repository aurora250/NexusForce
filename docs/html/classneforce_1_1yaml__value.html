详细描述

YAML值的抽象基类

所有YAML值类型的基类，定义了YAML值树的公共接口和类型系统。

每个 yaml_value 节点可携带可选的锚点和标签元数据：

  • anchor：锚点名（对应YAML中的 &anchor 语法）
  • tag：类型标签（对应YAML中的 !tag 语法）
注解
此类为抽象基类，不可直接实例化。
使用 type() 配合 as_*() 方法进行类型安全的向下转型。
