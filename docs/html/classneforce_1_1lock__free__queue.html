template<typename T>
class neforce::lock_free_queue< T >

无锁队列类模板

模板参数
T元素类型

基于 per-producer SPSC 子队列架构实现的无锁队列。 每个生产者线程拥有独立的 block-based SPSC 内队列，block 通过无锁 free_list 回收利用。 支持多生产者多消费者并发 push/try_pop 操作。
