详细描述

SQLite查询结果集类

实现idb_tb_result接口，提供SQLite查询结果的访问功能。 支持结果集遍历、列名获取和类型安全的数据读取。

主要功能：

  • 结果集元数据获取
  • 逐行遍历结果集
  • 支持多种数据类型转换
  • NULL值处理
  • 自动语句资源管理
注解
不允许复用。
