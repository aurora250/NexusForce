日志格式化器

根据指定的模式字符串格式化日志事件。 支持以下占位符：

  • {time} : 时间戳
  • {level} : 日志级别
  • {file} : 源文件名
  • {line} : 行号
  • {func} : 函数名
  • {thread} : 线程ID
  • {message} : 日志消息
  • {context.key} : 上下文中的指定键

示例模式："[{time}] [{level}] {file}:{line} - {message}"
