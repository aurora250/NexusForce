详细描述

PostgreSQL查询结果集类

实现idb_tb_result接口，支持结果集遍历、列名获取和类型安全的数据读取。

主要功能：

  • 结果集元数据获取
  • 逐行遍历结果集
  • 支持多种数据类型转换
  • BYTEA二进制数据处理
  • NULL值检测
