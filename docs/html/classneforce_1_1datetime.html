详细描述

日期时间类

组合日期和时间，支持时区处理。 提供多种格式的解析和格式化：

  • ISO格式（YYYY-MM-DDTHH:MM:SS）
  • ISO带时区（YYYY-MM-DDTHH:MM:SS±HH:MM 或 Z）
  • GMT格式（RFC 1123）
  • 简单格式（YYYY-MM-DD HH:MM:SS）
