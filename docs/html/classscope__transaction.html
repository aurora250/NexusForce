template<typename Connect>
class scope_transaction< Connect >

RAII事务作用域守卫

管理数据库事务的生命周期：

  • 构造时调用 begin()
  • commit() 显式提交事务（仅可调用一次）
  • 析构时若未提交则调用 rollback()

不可复制，支持移动语义。

模板参数
Connect连接类型，需满足 idb_connect 接口（提供 begin/commit/rollback）
