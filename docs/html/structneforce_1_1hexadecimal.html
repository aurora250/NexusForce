详细描述

十六进制数值包装类

提供十六进制数值的包装，支持从字符串解析、位操作、格式化等功能。 内部使用int64_t存储，支持64位以内的十六进制值。

constexpr pair< bool, byte_t > neforce::hexadecimal::xdigit_value ( const char high,
const char low )
inlinestaticconstexprnoexcept

将两个十六进制数字字符转换为对应的字节值。

参数
high高半字节十六进制字符（'0'-'9', 'A'-'F', 'a'-'f'）
low低半字节十六进制字符（'0'-'9', 'A'-'F', 'a'-'f'）
返回
pair<bool, byte_t>
  • first: true 表示转换成功，false 表示存在非法字符。
  • second: 转换成功时为 (xdigit_value(high) << 4) | xdigit_value(low) 的字节值； 失败时为 #invalid_xdigit。
