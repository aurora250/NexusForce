template<typename Res>
class promise< Res >

Promise类模板

模板参数
Res结果类型

表示一个异步计算的结果提供者，与future配对使用。 可以将计算结果或异常设置到promise中，关联的future可以获取这些结果。

注解
结果类型不能是数组、函数，必须是可析构类型
