详细描述

自适应扩容的动态缓冲区

适用于异步读取场景：prepare() 获取可写区域，commit() 标记已填充， consume() 移除已处理数据。内部自动扩容。

使用示例：

dynamic_buffer buf;
sock.async_read(ctx, buf.prepare(1024), [&](error_code ec, size_t n) {
buf.commit(n);
process(buf.data(), buf.size());
buf.consume(processed);
});

mutable_buffers neforce::dynamic_buffer::prepare ( size_t n)
inline

准备写入区域

参数
n至少需要的字节数
返回
可写的缓冲区序列

保证返回的缓冲区至少 n 字节可用。若内部空间不足则自动扩容。 返回的 mutable_buffers 指向内部存储，在下次 prepare 或对象析构前有效。

注解
多次 prepare 不重叠——每次 prepare 返回的缓冲区基于当前 write_pos_。
