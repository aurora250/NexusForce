详细描述

TCP服务器类

实现普通TCP服务器，使用tcp_acceptor接受连接。

主要功能：

  • TCP服务器启动和停止
  • SSL/TLS服务器支持
  • 线程池处理客户端连接
  • 非阻塞连接接受
  • 自定义客户端处理器
  • 异常处理回调
