详细描述

路径分割迭代器

将文件路径分割为各个组件（如目录名、文件名）的迭代器。 支持Windows和Linux的路径格式：

  • Windows: "C:\Windows\System32" -> "C:", "Windows", "System32"
  • Linux: "/usr/local/bin" -> "", "usr", "local", "bin"

使用前向迭代器接口，适用于范围for循环和标准算法。
