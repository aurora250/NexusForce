详细描述

跨平台 SIMD 整型算术运算

提供 128-bit 向量上的加法、减法、乘法、饱和运算、绝对值、 最大/最小值及平均等整型算术操作，覆盖 8/16/32/64 位元素宽度。 自动派发至 SSE2 / SSE4.1 / SSSE3 / AVX2 / NEON 或标量回退。
