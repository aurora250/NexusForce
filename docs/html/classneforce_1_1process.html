详细描述

进程管理类

支持 stdout/stderr 分离捕获、stdin 写入、工作目录和环境变量设置， 外部管道连接、文件重定向和进程链。

process p;
p.set_capture_stdout(true)
.set_capture_stderr(true)
.set_work_dir("/tmp");
p.start("/bin/ls", {"-la"});
int rc = p.wait(5000);
string out = p.stdout_output();
