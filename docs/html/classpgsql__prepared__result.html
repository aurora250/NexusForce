详细描述

PostgreSQL预处理语句结果集类

实现idb_prepared_result接口，提供PostgreSQL预处理语句查询结果的访问功能。

主要功能：

  • 结果集元数据获取
  • 逐行遍历结果集
  • 支持多种数据类型转换
  • BYTEA二进制数据处理
  • NULL值检测
注解
该类与pgsql_tb_result功能完全相同，但类型上区分了普通查询和预处理语句查询， 便于接口设计和类型安全。
