详细描述

文件操作类

提供完整的文件操作接口，包括：

  • 同步/异步读写
  • 内存映射文件
  • 文件锁定
  • 文件属性管理
  • 文件比较和差异分析

线程安全，支持移动语义，不支持拷贝。
