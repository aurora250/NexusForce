跨平台 SIMD 比较运算

提供 128-bit 向量上的整型及浮点逐元素比较操作， 返回全 1（真）或全 0（假）掩码向量。 自动派发至 SSE2 / SSE4.1 / AVX2 / NEON 或标量回退。
