YAML时间戳值类型

表示YAML中的时间戳值。内部使用 datetime 对象存储， 支持 ISO 8601 和 RFC 3339 格式的解析。

支持的格式示例：

  • 日期时间：2024-01-15T10:30:00Z
  • 仅日期：2024-01-15
  • 带时区偏移：2024-01-15T10:30:00+08:00
