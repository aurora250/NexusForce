详细描述

template<typename Key, typename Compare = less<Key>, typename Alloc = allocator<Key>>
class sparse_set< Key, Compare, Alloc >

稀疏集合容器

模板参数
Key键类型
Compare键比较函数类型，默认为less<Key>
Alloc分配器类型

sparse_set是一种关联容器，存储唯一的键值，每个键在容器中唯一。 元素按照键的顺序自动排序，排序标准由Compare函数对象指定。 底层使用有序平坦数组实现，查找O(log n)，迭代缓存友好。

注解
适用于查找频繁、修改较少且需要有序遍历的场景。
警告
插入和删除操作为O(n)，可能使所有迭代器失效。
