MSVC内部函数替代实现

此文件提供了MSVC编译器内部函数的替代实现，使得这些函数在其他环境也能使用。

主要功能：

  • 带进位的64位加法
  • 带借位的64位减法
  • 64位无符号乘法
  • 128位无符号除法
