详细描述

YAML序列值类型（数组）

表示YAML中的有序值列表。支持两种集合样式：

  • **块样式**（Block）：每行以 - 开头的缩进列表
  • **流样式**（Flow）：方括号内的逗号分隔列表 [a, b, c]

序列中的元素可以是任意YAML值类型（包括嵌套的序列和映射）。

注解
此类禁止拷贝，仅允许移动。
