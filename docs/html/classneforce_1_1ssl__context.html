详细描述

SSL/TLS上下文管理类

封装OpenSSL的SSL_CTX对象，提供SSL连接的配置和管理功能。 支持证书加载、验证配置、密码套件设置等。

主要功能：

  • SSL上下文创建和配置
  • 证书和私钥加载
  • CA证书验证配置
  • 密码套件和协议版本设置
  • ALPN（应用层协议协商）支持
  • 会话缓存和超时配置
注解
上下文对象是线程安全的，可以被多个SSL连接共享。
