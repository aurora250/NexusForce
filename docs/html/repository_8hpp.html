泛型 Repository 模式实现

在 sql_mapper 之上提供开箱即用的 CRUD 操作。 通过反射元数据自动完成实体与数据库表之间的映射。

使用示例：

repository<User, idb_tb_connect> repo(conn);
repo.create_table();
User u{0, "Alice"};
repo.insert(u);
auto users = repo.find_all();
auto user = repo.find_by_id(meta_any(1));
