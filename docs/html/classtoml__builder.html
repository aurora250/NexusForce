详细描述

toml配置构建器

提供流式接口构建toml配置格式，支持以下特性：

  • 链式调用构建表格和数组
  • 自动类型转换（整数、浮点数、布尔值、字符串）
  • 函数式构建嵌套结构
  • 集合类型自动转换（可迭代对象、映射表）
  • 上下文管理（自动维护当前表格/数组状态）
  • 支持所有toml字符串类型（Basic, Literal, Multi-line）
  • 支持所有toml日期时间类型
