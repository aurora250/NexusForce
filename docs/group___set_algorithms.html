计算两个已排序范围 [first1, last1) 和 [first2, last2) 的并集。 结果包含所有出现在任一输入范围中的元素，重复元素只出现一次。

前提条件：

  1. 两个输入范围都已按升序排序
  2. 输出范围不与输入范围重叠
