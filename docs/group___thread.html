◆ sleep_for_ms() [2/2]

void NEFORCE_API sleep_for_ms ( uint32_t ms,
bool busy_wait )
noexcept

精确睡眠指定毫秒数

参数
ms要睡眠的毫秒数
busy_wait是否使用忙等待获得更高精度

提供相对精确的睡眠功能。当use_busy_wait为true时，使用忙等待+系统睡眠组合 以获得更高的精度，但会增加CPU使用率。为false时使用纯系统睡眠。

注解
Windows平台最小精度通常为1-15ms，Linux为1ms，忙等待可达到微秒级精度
