详细描述

template<typename T, typename Alloc = allocator<T>>
class vector< T, Alloc >

动态大小数组容器

模板参数
T元素类型
Alloc分配器类型

动态增长的数组容器，提供连续的存储空间和随机访问能力。 支持在末尾高效插入/删除元素，以及在任意位置插入/删除。
