template<size_t N>
class bitset< N >

固定大小的位集

模板参数
N位数，在编译时确定

bitset表示一个固定大小的二进制位序列，提供对每个位的独立访问 以及常见的位操作（与、或、异或、移位等）。存储效率高，操作速度快。 位数N在编译时确定，因此不能动态改变大小。
